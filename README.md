# Ashrita's Birthday Surprise 🎂

A small static birthday website made with plain HTML, CSS and JavaScript.

## Add photos

Put 2–3 photos in `assets/` and then add them to `index.html` wherever you want.
The current version intentionally keeps the message-focused layout clean.

## Publish with GitHub Pages

1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder.
3. Go to **Settings → Pages**.
4. Choose **Deploy from a branch** and select `main` / root.
5. Open the generated GitHub Pages URL.

No backend is required.
